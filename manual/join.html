Join the Sec Community

Sec is a new programming language being built in the open. Building a language takes much more than writing a compiler, and everyone who wants to help is welcome.

You do not need to be a compiler engineer or programming-language expert. If you enjoy programming, testing software, designing APIs, writing documentation, building websites, working with hardware, reviewing technical ideas, or simply trying new languages, there are useful ways to take part.

Find your way to contribute

  • Try Sec. Write programs, explore the language, and tell us where something is confusing, awkward, missing, or broken.
  • Discuss and challenge the design. Programming-language experience is valuable, but so are concrete examples from everyday programming. Well-reasoned criticism is welcome.
  • Write code. Work on the compiler, standard library, tools, tests, examples, platform support, or programs written in Sec.
  • Test and review. Reproduce bugs, reduce failing examples, check diagnostics, review APIs, or compare the implementation with the specification.
  • Improve documentation and the website. Technical writing, HTML, CSS, accessibility, navigation, UX, and visual design are all part of making Sec usable.
  • Bring domain knowledge. Experience with networking, operating systems, embedded systems, hardware, Unicode, security, file formats, mathematics, or other specialist areas can help shape the standard library and platform support.

For a more detailed list of areas where help is currently useful, see Help Wanted.

Where to meet us

GitHub is the best place for work that should remain easy to find later: bug reports, design discussions, implementation work, and pull requests.

Discord is available for more informal discussion, questions, ideas, and getting to know other people interested in Sec.

Getting started

  1. Read the introduction to understand what Sec is trying to achieve.
  2. Browse the manual or the Help Wanted page and choose something that interests you.
  3. Try Sec, review an area you know well, or visit the repository if you want to work directly on the project.
  4. Join the discussion on Discord or open a discussion or issue on GitHub when you have a question, idea, problem, or proposal.
Remember: Sec is still at version 0.1. The language and implementation will change, and feedback now can influence both. Small contributions are welcome — and so are difficult questions.
