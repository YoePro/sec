Help Wanted

Sec is in early development and we need help. No compiler experience required — there's work for everyone.

What we need

  • Compiler development — Help build the first compiler in Go (version 0.3). Later we bootstrap by rewriting the compiler in Sec itself (version 0.4).
  • Standard library — Design and implement modules for I/O, collections, math, strings, and more.
  • Documentation — Write examples, fix gaps in the manual, and improve the language reference.
  • Testing — Write test cases for valid and invalid programs. Check the implementation status table for gaps.
  • Dogfooding — Write real programs in Sec, find what breaks, and report it.
  • Design feedback — Review the language spec and suggest improvements before things solidify.

How to get started

  1. Clone the repository and read the introduction.
  2. Check the implementation status to see what's done and what's missing.
  3. Pick something that interests you — or open a discussion on GitHub if you're unsure.
  4. Open a pull request or an issue to get involved.
Remember: We're at version 0.1. Everything is in flux and your input matters now more than ever.
