Indexing

Indexing provides element access for arrays, slices, and other sequence types. It is a fundamental operation that produces a place expression — a location that can be read from, written to, or borrowed.

Syntax

target[index]

The target may be:

  • an array
  • a shared slice (ref T[])
  • a mutable slice (ref mut T[])
  • a nested indexing expression

Examples:

let value := values[3]
matrix[row][column]
buffer[index + offset]

Valid Index Types

The index must have an integer type:

  • All built-in signed and unsigned integer types are valid.
  • A named integer type may be used when its underlying representation is integer and it has no incompatible unit dimension.
Rule: Floating-point, decimal, boolean, string, and unit-bearing indexes are invalid. Negative signed indexes are invalid.

Indexing Result

Indexing produces a place expression. It does not inherently copy, move, or borrow an element — the use context determines the operation.

Read or copy:

let value := values[index]

Assignment:

values[index] = value

Shared element borrow:

let element := ref values[index]

Mutable element borrow:

let element := ref mut values[index]

The place type is the array or slice element type. The place mutability is derived from the target:

TargetElement Place Mutability
immutable array bindingread-only
mutable array bindingmutable
ref T[]read-only
ref mut T[]mutable

Assignment Through Indexing

Assignment requires:

  • a mutable element place
  • a right-hand value assignable to the element type
  • no conflicting active borrow
  • a valid runtime index
  • a completely evaluated right-hand expression before replacement

When replacing an owned non-trivial array element, the old element is destroyed exactly once after the replacement value has been successfully evaluated and ownership transfer has been validated.

Reading and Moving Elements

Reading an implicitly copyable element copies it:

let value := numbers[index]

For the initial implementation, moving a move-only element out through array or slice indexing is invalid:

let resource := resources[index]  // Invalid for move-only Resource

The programmer must borrow the element instead:

let resource := ref resources[index]
Rule: A slice can never transfer ownership of an element merely through indexing because the slice does not own the element.

Bounds Checking

Safe array and slice indexing is bounds checked.

For an array T[N], a valid index satisfies:

0 <= index < N

For a slice, a valid index satisfies:

0 <= index < slice.len

A constant invalid index is a compile-time error:

let values: int[4] := [1, 2, 3, 4]
let invalid := values[4]  // Compile-time error

A runtime index requires a runtime bounds check. Safe bounds checks remain required inside an unsafe block.

Rule: Unchecked access belongs to explicit RawPtr[T] operations and is not ordinary array or slice indexing.

Array Length Member

Arrays expose .len:

let arrayLength := values.len

The type of len is uint. For arrays, len is a compile-time constant equal to N.

The len() Function

The compiler-known core function len is the canonical length operation for index arithmetic:

let arrayLength := len(values)
let sliceLength := len(view)

It accepts an owning T[], ref T[], or ref mut T[], and returns int. This avoids conversions when comparing a length to int indexes or offsets.

Rule: The member property .len remains uint; use len(...) when an int result is required.

Pointer Access

Direct .ptr access is not part of the initial safe array and slice implementation. Conversion of an array or slice address into RawPtr[T] follows the raw-pointer rules and requires an explicit unsafe operation.

Iteration

Arrays and slices may participate in for iteration. Iteration must use the same indexing, copy, and borrow rules defined by the array and slice chapters.

// Element iteration
for value in values {
    Process(value)
}

// Index and element iteration
for index, value in values {
    Print(index, value)
}

The initial implementation must not silently move move-only elements out of an array or slice during iteration.
