## 1. Struct field tags — small

Governance: `frontend.struct-field-tags`

Status: completed (2026-08-27)

- Confirmed that `rules/declarations/struct.md` section 4 already defines the
  canonical raw escape rule: the compiler preserves escape spelling and uses it
  only to locate the structural closing quote.
- Confirmed that the existing production path already preserves ordered tags
  through generic specialization, Semantic IR, and Sec-MLIR lowering; no new
  production behavior was added for this part.
- Added regression coverage for that existing path, including escaped quotes
  and whitespace.
- Added immutable Sema field-metadata facts and attached ordered tags to
  resolved struct-member facts, so consumers do not reconstruct metadata from
  syntax.
- Added LSP field hover for open-key tags with raw escape spelling and value
  whitespace preserved.
- Reconciled scope with MLIR package 13: reflection and serialization behavior
  are explicitly outside that package; their future consumers can use the
  preserved metadata without core tag-key semantics being invented here.
