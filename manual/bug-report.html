Report a Bug

Found a compiler crash, wrong codegen, or a documentation error? Please file an issue on GitHub.

Before you report

  • Check the existing issues to avoid duplicates.
  • Note your Sec version and platform.
  • Prepare a minimal code snippet that reproduces the problem.

How to report

Open an issue on the GitHub issue tracker. Use the bug report template if one is available, and include:

  • A clear title describing the problem
  • Steps to reproduce
  • Expected vs. actual behaviour
  • Compiler output or error message
Tip: The smaller your reproduction case, the faster we can fix it.
