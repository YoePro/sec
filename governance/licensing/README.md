# Sec licensing governance

Status: adoption pending | Revision: 1 | Date: 2026-11-25

This directory records legal/compliance governance separately from the compiler
implementation ledger. Do not add these registers to governance/index.yaml or
count them as compiler implementation progress.

- [policy.md](policy.md): operational licensing and release policy.
- [licensing.yaml](licensing.yaml): machine-readable policy and adoption gates.
- [third-party.yaml](third-party.yaml): initial dependency inventory.
- [adoption.md](adoption.md): integration and verification checklist.

The baseline is YoePro/sec main commit
`6e589f2843aa3fc1fa812ad11f574d6d924b6dcf`. Inventory entries represent observed
manifests, not verified distribution contents or cleared rights.
